# SINGE

Sistema Integrado de Gestão Educacional

> 🚧 Em desenvolvimento

## Objetivo

O SINGE é um sistema web desenvolvido em Python e Flask para gerenciamento escolar.

A ideia é simples:

> **Toda funcionalidade deve economizar tempo da Secretaria Escolar.**

## Tecnologias

- Python
- Flask
- HTML
- CSS
- Bootstrap
- SQLite
